# My Portfolio

A small website that shows the projects I have built. You log in and add projects with a title, a description and a link.

## Run it

You need [Node.js](https://nodejs.org/) 18 or newer.

```bash
npm install && npm start
```

Then open http://localhost:3000 and log in with username `alex` and password `portfolio123`.

## Files

- `server.js`: the Express server. It handles logging in and saving projects.
- `public/index.html`: the page.
- `public/app.js`: the code that runs in the browser.
- `public/style.css`: how the page looks.
