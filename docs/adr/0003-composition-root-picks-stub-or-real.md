# A composition root picks a stub or real implementation per module

The five module packages may depend only on `@aha/contracts` (ADR-0002), so none of them can import the others to wire a session. `apps/aha` is the composition root: it is the only package that depends on all of them, and it builds `AhaModules` from `aha.config.json` (overridden by `AHA_AGENT_HOST`, `AHA_DECISIONS`, `AHA_LEARNER_MODEL`, `AHA_TEACHING`, `AHA_BACKGROUND`), choosing `stub` or `real` for each module. The App Shell (`@aha/app`) owns the backend wiring and the server but receives the modules as a parameter. Every module package ships a stub behind its contract; when a real implementation lands, its owner registers it in `apps/aha/src/modules.ts`. The session-replay test lives in `apps/aha` because it crosses every module.
